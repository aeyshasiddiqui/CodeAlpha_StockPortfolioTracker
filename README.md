# 📈 Stock Portfolio Tracker

## 📌 Project Description
This is a simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship. The program allows users to enter stock names and quantities, calculates the total investment value using predefined stock prices, and displays the final portfolio value.

## ✨ Features
- User-friendly console interface
- Enter stock names and quantities
- Calculates total investment value
- Uses a predefined dictionary for stock prices
- Optionally saves the portfolio details to a text file

## 🛠️ Technologies Used
- Python 3
- Dictionaries
- Loops
- Functions
- File Handling (Optional)

## ▶️ How to Run
1. Clone this repository.
2. Open the project in any Python IDE or terminal.
3. Run the Python file:
   ```bash
   python stock_portfolio_tracker.py
   ```
4. Enter the stock name and quantity when prompted.
5. View the total investment value.
